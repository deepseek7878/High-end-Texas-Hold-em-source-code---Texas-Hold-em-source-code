# Texas Hold'em Poker Engine Source Code

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [GitHub Pages](https://deepseek7878.github.io/texas-holdem-engine/)

Texas Hold'em Poker Engine is a high-performance poker game engine source-code project for multiplayer poker games, private tables, club rooms, lobby games, tournament events, equity simulation and AI training environments.

The project covers the core Texas Hold'em game flow, including dealing, betting rounds, check, call, raise, fold, all-in, side pots, hand evaluation, player state, table state, event push and multi-table management.
